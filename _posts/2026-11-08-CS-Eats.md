## Overview

For this programming assignment, I developed a restaurant management and food delivery simulation in C.

The program allows users to manage a restaurant, register customers, create and manage food orders, and simulate the delivery process. It also includes features such as order discounts, customer management, order cancellation and a simulated delivery driver.

## Implementation

The assignment involved applying C programming concepts to build a system that manages interconnected data structures and simulates a real-world ordering and delivery process.

Key concepts included:

- Linked lists for managing customers and orders
- Structs and enums for representing restaurants, customers, orders and driver states
- Pointers for manipulating dynamically allocated data
- Dynamic memory allocation and deallocation
- Searching, inserting and removing nodes from linked lists
- Sorting and merging linked lists
- Functions and modular programming
- State management for simulating the delivery process

I also implemented more advanced features such as reordering previous purchases, merging customer accounts and simulating a delivery driver handling multiple orders.

## What I Learned

This assignment significantly strengthened my understanding of C programming, particularly linked lists, pointers and dynamic memory management.

One of the more challenging aspects was managing relationships between different linked lists, especially when customers and orders could be added, removed, merged or reordered.

I also gained experience designing more complex programs by breaking functionality into smaller helper functions and managing multiple interacting components.

The delivery simulation was particularly interesting because it required tracking the driver's state and updating the system as orders progressed through different stages of delivery.
