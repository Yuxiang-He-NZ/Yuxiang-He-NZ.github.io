## Overview

This is a assigment is about simulating trains and having them go to various stops picking up people and freights. To see if certain routes can be taken or not, if the frieghts will make it on time etc.

## Gameplay and Features

This simulation can create variuous station ids, which the train object can go too. There are also tracks connecting stations together and certain trains can go on certain tracks. There is 3 types of trains each with unique constrants such as only being able to go on cyclical route, can pick up passengers and freights etc..

things that makes this hard is when you need to implemenet the ticks which does the simulation. So after every tick you should be able to find every train and passenger and each of their locations.

Furthermore there will breakable tracks which will need special repair passengers to fix on the train otherwise the train would stop.

There is also Refridgerated freights which you have to simulate beforehand to see if it can make it to the destanation before spoilage which was hard.
